# mobi-life-tool (마비노기 모바일 생활 자동화 대시보드)

AI 없이 브라우저에서 바로 실행·제어할 수 있는 독립 로컬 생활 자동화 대시보드 배포 저장소입니다.

## 설치 방법
1. 우측 **Releases** 탭에서 최신 버전의 `mobi-life-tool_Setup_vX.Y.Z.exe`를 다운로드해 실행하세요.
2. Python 런타임이 내장되어 있어 별도 설치 없이 바로 실행됩니다.
3. 설치 후 바탕화면의 **mobi-life-tool** 바로가기를 실행하면 검은 콘솔 창 없이 백그라운드에서 실행되고 브라우저 대시보드가 자동으로 열립니다.

## 주요 기능
- **실시간 큐·러너 제어**: 작업 대기열 조회, 개별 취소, 일시정지/재개/전체 취소, 실시간 로그 스트리밍
- **원클릭 효율 제작**: 카테고리별 효율 1위 조회 및 안전 배치 연속 제작
- **커넥터 상태 알림**: `MabinogiMobile_CLI.exe` 미연결 시 대시보드 알림 안내
- **중복 실행 방지**: 이미 실행 중이면 새 프로세스 없이 기존 대시보드 화면을 바로 오픈
- **게임 종료 시 자동 종료**: `MabinogiMobile.exe` 및 CLI 종료 감지 시 진행 중 작업 안전 복귀 후 자동 종료

## 자동 업데이트
- 새 버전이 출시되면 대시보드 상단에 **새 버전 알림 배너**가 자동으로 표시됩니다.
- **지금 업데이트** 버튼을 누르면 사용자 데이터(작업 DB·축약어·수동 설정)를 보존한 채 최신 패치만 자동 적용됩니다.
