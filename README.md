# mobi-life-tool

**마비노기 모바일 생활자동도구 (AI 사용안함)**

AI 모델·API 키·별도 런타임 설치 없이 Windows PC에서 독립 실행되는 마비노기 모바일 채집·가공·제작 자동화 로컬 웹 대시보드입니다.

---

## 다운로드 안내 (Releases 파일 구분)

우측 [**Releases**](https://github.com/lixsoc/mobi-life-tool/releases/latest)에서 최신 버전을 받을 때 아래 파일만 받으시면 됩니다.

- **mobi-life-tool_Setup_vX.Y.Z.exe** ← **일반 사용자 설치용 (이 파일만 다운로드하세요)**
- mobi-life-tool_Patch_vX.Y.Z.zip / .sha256 ← 앱 내부 원클릭 자동 업데이트 전용 파일 (직접 다운로드할 필요 없음)

---

## 기본 설치 방법

1. [**최신 Releases 페이지**](https://github.com/lixsoc/mobi-life-tool/releases/latest)에서 mobi-life-tool_Setup_vX.Y.Z.exe를 다운로드합니다.
2. 다운로드한 설치 파일을 실행해 설치를 완료합니다. (Python 3.12 런타임이 내장되어 있어 별도 설치가 필요 없습니다.)
   - Windows SmartScreen 보호 창이 뜨는 경우 **추가 정보 → 실행**을 눌러 진행하세요.
3. 설치가 완료되면 바탕화면에 **mobi-life-tool** 바로가기가 생성됩니다.

---

## 기본 실행 및 사용 방법

1. **마비노기 모바일 게임**과 커넥터(MabinogiMobile_CLI.exe)를 먼저 실행합니다.
   - 기본 경로(C:\Nexon\MabinogiMobile\MabinogiMobile_CLI.exe)와 다른 곳에 설치되어 있다면 실행 후 ⚙ 설정 탭에서 경로를 지정하세요.
2. 바탕화면의 **mobi-life-tool** 아이콘을 더블클릭합니다.
   - 검은 콘솔 창 없이 백그라운드에서 실행되며 웹 브라우저 대시보드가 자동으로 열립니다.
3. 대시보드 우측 상단의 **🔄 CLI 목록 수집** 버튼을 눌러 현재 인벤토리와 제작·가공 가능 목록을 동기화합니다.
4. **🛠 제작 카탈로그** 탭에서 제작품 또는 가공품을 선택하고, 원하는 아이템을 클릭해 수량과 연속 루프(--loop) 여부를 확인한 뒤 **제작 파이프라인 시작**을 누릅니다.
5. **📋 작업 큐** 탭에서 실시간 진행·대기 작업, 완료 목록, 실패 목록을 확인하고 개별 취소·초기화를 제어할 수 있습니다.
6. 사용을 마칠 때는 상단의 **⏻ 종료** 버튼을 눌러 대시보드와 백그라운드 스케줄러를 안전하게 종료하세요. (게임 종료 시에도 자동 안전 종료됩니다.)

---

## 주요 기능

- **AI 미사용 100% 로컬 자동화**: 외부 AI 호출 없이 채집 → 가공 → 제작 연쇄 파이프라인을 로컬 규칙으로 실행
- **제작 카탈로그 & 즐겨찾기**: 제작품/가공품 분류 필터, 효율순 정렬, 개인 로컬 즐겨찾기 및 축약어 검색
- **스마트 작업 큐**: 진행·대기 큐와 완료/실패 목록 분리, 게임 확인 팝업 감지 시 작업 보존 안전 일시정지, 즉시 일시정지/취소
- **원클릭 자동 업데이트**: 새 버전 출시 시 상단 배너의 지금 업데이트 버튼으로 개인 데이터(즐겨찾기·축약어·설정)를 유지한 채 자동 패치
- **버그 신고**: 상단 🐞 버그 신고 버튼으로 PC 사용자명이 익명 마스킹된 백그라운드 로그를 간편 전송
