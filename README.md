# MobinogiAuto (마비노기 모바일 자동화 대시보드)

AI 없이 브라우저에서 바로 실행·제어할 수 있는 독립 로컬 자동화 대시보드 배포 저장소입니다.

## 설치 방법
1. 우측 **Releases** 탭에서 최신 버전의 `MobinogiAuto_Setup_vX.Y.Z.exe`를 다운로드해 실행하세요.
2. Python 런타임이 내장되어 있어 별도 설치 없이 바로 실행됩니다.
3. 설치 후 바탕화면의 **마비노기 모바일 자동화 대시보드** 바로가기를 실행하세요.

## 자동 업데이트
- 새 버전이 출시되면 대시보드 상단에 **새 버전 알림 배너**가 자동으로 표시됩니다.
- **지금 업데이트** 버튼을 누르면 사용자 데이터(작업 DB·축약어·수동 설정)를 보존한 채 최신 패치만 자동 적용됩니다.
